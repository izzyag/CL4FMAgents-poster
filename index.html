III. Reference Implementation & Qwen2.5 LoRA Post-Training

Drop-in replacement for torch.optim.SGD

By formulating continual learning as element-wise inverse preconditioning using a diagonal Empirical Fisher (F) and normalized trajectory accumulator (S̄), TMLN maintains strict O(N) memory complexity. This enables scalable Foundation Model LoRA fine-tuning where Kronecker-factored methods such as K-FAC (O(N²), 16.86× slower) become computationally prohibitive. 

from tmln_optim import TMLNOptimizer

# 1. Initialize as a drop-in replacement for standard torch.optim.SGD
optimizer = TMLNOptimizer(model.parameters(), lr=0.01, lambda_base=0.1, gamma=1.0)

# 2. Standard optimization step: applies inverse preconditioning (F + lambda + gamma * S_bar)^(-1)
loss.backward()
optimizer.step()

# 3. Consolidate parameter trajectory & update empirical Fisher at task boundaries
optimizer.end_task(model, replay_buffer_batches)
